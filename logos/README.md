# Logo Database

This is the large brand/logo database. Physical folders are primarily **source collections**; logical categories and search live in `manifest/logos/`.

```text
svglogos/           current SVG Logos mirror
detain/             detain/svg-logos snapshot
worldvectorlogo/    WorldVectorLogo collection (shard large imports alphabetically)
simple-icons/       Simple Icons
devicon/            Devicon
svgl/               SVGL
dashboard-icons/    Dashboard Icons
vectorlogozone/     VectorLogoZone
curated/            manually selected high-value variants
```

Do not treat every SVG file as a unique brand. Canonical brand IDs can have multiple source variants (icon, wordmark, horizontal, vertical, monochrome, etc.).
