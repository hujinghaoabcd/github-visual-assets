# Reusable Library

Curated cross-project visual building blocks. This is the reusable shelf, not a raw upstream mirror.

- `banners/` — generic README/documentation banners
- `illustrations/` — coding/research/GIS/AI/data illustrations
- `animations/` — reusable GIF/animated SVG/Lottie assets
- `backgrounds/` — gradients, grids, maps, patterns and textures
- `icons/` — functional/non-brand UI/map/chart/file icons
- `badges/` — custom/static/Shields helpers
- `decorations/` — dividers, waves, blobs, dots and shapes
- `mockups/` — browser, terminal, desktop, laptop and mobile frames
- `data-viz/` — reusable chart/map visual components and palettes
- `diagram-elements/` — generic nodes, connectors and containers
