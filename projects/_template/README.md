# Project Visual Kit Template

Recommended structure:

```text
identity/
  logo/
  icon/
  favicon/
readme/
  hero/
  section-headers/
  badges/
covers/
publication/
social/
diagrams/
figures/
screenshots/
demos/
docs/
previews/
project.yml
```

Keep only sections the project actually needs. Shared imagery should be referenced from `library/` rather than copied.
