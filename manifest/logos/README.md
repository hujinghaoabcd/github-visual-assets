# Canonical Logo Metadata

Planned/curated records:

- `brands.jsonl` — one canonical record per brand
- `aliases.json` — spelling/name/slug aliases
- `variants.jsonl` — source-specific files and forms
- `duplicates.jsonl` — exact/near duplicate relationships
- `checksums.jsonl` — normalized SVG/file hashes

Semantic classification belongs here rather than in physical source folders.
