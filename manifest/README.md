# Manifest

Machine-readable metadata is the source of truth for search, taxonomy, provenance, aliases, variants and duplicate detection.

- `assets.yml` — first-party starter registry
- `taxonomy/` — controlled categories and tag policy
- `logos/` — canonical brands, aliases, variants, duplicates and checksums
- `sources/` — upstream collection snapshots
- `licenses/` — source/restriction metadata
- `schemas/` — validation schemas
- `indices/` — generated search/checksum indexes
