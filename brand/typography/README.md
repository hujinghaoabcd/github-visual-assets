# Typography

Preferred stack for generated assets:

- **Latin / UI:** Inter or system sans-serif fallback
- **Chinese:** Noto Sans SC / Source Han Sans SC / system sans-serif fallback
- **Code:** JetBrains Mono / ui-monospace / monospace fallback

Do not commit font binaries to this repository. Use locally installed or web-safe/system fallbacks during export, and convert text to paths only when a final vector deliverable truly requires it.

Hierarchy recommendation: 800/700 for hero titles, 600 for section titles, 400/500 for supporting text.
