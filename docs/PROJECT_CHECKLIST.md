# Project Visual Checklist

Use this checklist for each important repository.

## Identity
- [ ] Project logo / mark
- [ ] Light and dark compatibility
- [ ] Project family selected
- [ ] Colors match shared tokens

## README
- [ ] 1600 × 600 hero or compact banner
- [ ] Meaningful badge row
- [ ] Architecture / workflow figure
- [ ] Demo GIF or screenshots where useful
- [ ] All images have alt text

## Sharing
- [ ] 1280 × 640 social preview
- [ ] 1200 × 630 project cover if needed
- [ ] Square thumbnail if cataloged

## Files
- [ ] Editable source retained
- [ ] SVG optimized
- [ ] Raster images compressed
- [ ] Naming convention followed
- [ ] No secrets/private data in screenshots

## Licensing
- [ ] Every third-party asset has source + license
- [ ] THIRD_PARTY.md updated
- [ ] manifest/assets.yml updated
