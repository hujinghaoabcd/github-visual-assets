# Naming Conventions

Use lowercase kebab-case for asset files.

## Pattern

```text
<project-or-topic>-<asset-type>-<variant>-<size>.<ext>
```

Examples:

```text
dh-stgcn-hero-dark.svg
pykdex-project-cover-1200x630.png
geo-grid-background-light.svg
research-demo-training.gif
```

## Variant suffixes

Use predictable suffixes: `-light`, `-dark`, `-mono`, `-outline`, `-filled`, `-compact`, `-square`, `-horizontal`, `-vertical`, `-animated`.

Avoid names such as `final-final2.png`, `new-logo.svg`, `image123.png`, or source-site download names that provide no semantic meaning.
