# Asset Lifecycle

```text
discover / create
      ↓
provenance + license review
      ↓
source collection OR editable master
      ↓
classify / dedupe / tag
      ↓
curate or compose for profile/project
      ↓
validate / optimize / thumbnail
      ↓
manifest index
      ↓
README / docs / site reuse
      ↓
archive when superseded
```

Unknown-license material should not enter the reusable public library until reviewed.
