# Licensing and Provenance

## Repository-owned work

Code and automation are MIT licensed. Original visual assets created specifically for this repository are CC BY 4.0 unless marked otherwise.

## Third-party assets

Never infer reuse permission from the fact that an image appears in a public GitHub repository. Find the original source and exact usage terms.

For each third-party asset record: original URL, author/organization, license, retrieval date, local path, modifications, and where it is used.

## Trademarks

Open-source icon licenses do not necessarily grant unrestricted trademark rights. Product and company logos should be used descriptively and according to their brand guidelines.

## AI-generated assets

Record that the asset was AI-assisted/generated, the tool/model when useful, the date, and any important source/reference constraints. Do not present a copied trademark or identifiable third-party artwork as an original brand mark.

## Unknown provenance

If provenance cannot be established, keep the file out of the reusable library until it is resolved.
